# ScreenRuler 屏幕标尺

用于屏幕测量、布局检查和桌面对齐的 Windows 工具。提供贴边标尺、参考线、标点、连续测距与窗口吸附，支持多显示器独立配置。

## 功能概览

| 功能 | 用途 |
| --- | --- |
| 屏幕标尺 | 顶部和左侧显示标尺，支持像素、厘米、英寸，以及鼠标位置指示和数值提示 |
| 参考线 | 拖出或双击创建，移动时显示位置；支持实线、虚线、点线及位置保存 |
| 快捷与连续测距 | 查看边界跨度和间距，或连续点选绘制折线、闭合轮廓 |
| 屏幕标点 | 标记指定位置，支持圆形、方形、菱形、十字和自定义图片 |
| 吸附 | 参考线对齐定位点、窗口、控件和图像边缘；外部窗口对齐参考线划分的区域 |
| 命名定位点 | 在标尺上保存有名称的固定位置或百分比位置，按屏幕管理 |
| 物理校准与精度 | 每屏分别校准水平、垂直物理尺寸；各单位独立设置刻度和小数位 |
| 多屏与显示控制 | 每屏管理辅助内容，角落按钮切换当前屏幕，托盘统一切换所有屏幕 |
| 外观与操作 | 配置颜色、线型、粗细、透明度和操作按键，支持中英文与开机启动 |
| 操作手册 | 应用内提供可搜索的分章手册、示意图、术语解释和当前配置的按键 |

## 下载与启动

面向 Windows 10/11 x64。当前仅提供精简版（不含运行时），从 [Releases](../../releases) 下载：

| 包类型 | 使用条件 |
| --- | --- |
| 精简版（`framework-dependent`） | 需要安装 [.NET Desktop Runtime 5.0 x64](https://dotnet.microsoft.com/en-us/download/dotnet/5.0)，普通 .NET Runtime 不包含 WPF 桌面组件 |

1. 下载程序 ZIP 附件；GitHub 自动提供的 `Source code` 是源码包。
2. 解压到当前用户可写的目录，运行 `ScreenRuler.exe`。
3. 右击左上角按钮或托盘图标，打开“设置”或“使用帮助”。

当前版本基于 .NET 5；该运行时已结束官方支持，详见 [Microsoft 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/5.0)。

## 快速上手

### 参考线与标点

- 从顶部标尺向下拖出**水平参考线**，从左侧标尺向右拖出**垂直参考线**。默认可直接拖动；按键拖拽模式需要先按住参考线操作键。
- 双击顶部标尺创建垂直参考线，双击左侧标尺创建水平参考线。
- 按住 `Left Shift` 拖动已有参考线；同时按住 `Left Ctrl` 可吸附。新建参考线时，按住 `Left Ctrl` 即可吸附。
- 按住 `Left Shift` 双击参考线删除，或将其拖回对应标尺区域。虚线空隙及线旁也可选中。
- 从角落按钮向屏幕内拖出**标点**；按住 `Left Shift` 移动或双击删除，也可拖回左上角删除。

### 快捷测距

单独按住 `Left Alt` **500 毫秒**，待测距出现后移动鼠标查看距离；没有点击时，松键即结束，不保留结果。

在测距已出现后，按 `Left Shift` 仅显示垂直距离，按 `Left Ctrl` 仅显示水平距离。可在设置中选择最近边界跨度、到最近参考线或屏幕边缘的四向间距，以及到屏幕四边的间距；测距单位可跟随标尺或单独指定。

等待长按触发期间，按其他键、点击或滚动会取消本次触发，因此可以正常使用 `Alt+Z` 等组合键。触发测距后，后续键盘、鼠标按键和滚轮输入由测距功能接管，松键后恢复。

### 连续点选测距

1. 单独长按 `Left Alt`，等待测距出现。
2. 左键点击起点，移动鼠标预览下一段；再次点击确认下一点，可连续点选。
3. **松开测距键**：结束并保留已确认线段，丢弃未确认的预览段；仅一个点时不保留。
4. **双击终点或按 `Enter`**：确认终点并连接起点。至少三个不同节点才能闭合，两个节点保留为一条线段。
5. 完成后松开测距键，再长按即可开始下一次测量。无需按 `Esc`。

绘制限定在起点所在屏幕。需要对齐定位点、参考线或屏幕边缘时，在测距启动后按住吸附键。按住 `Left Shift` 悬停已完成的测距线，双击可删除整条结果。测距结果仅在本次运行期间保留。

### 定位点、校准与精度

**定位点**是在标尺上保存的命名位置。右击标尺添加，输入名称及 `px`、`cm`、`in` 或百分比数值；悬停可查看名称和位置。在“设置 → 定位点”按屏幕编辑、停用、删除或恢复默认中心点。原中位线由两个可删除的 `50%` 定位点表示。

**物理校准**用于让厘米、英寸与实体尺对应。在“设置 → 物理校准”选择屏幕，用实体尺测量水平和垂直校准线，输入实际厘米数并应用。每屏独立保存，分辨率或旋转变化时重新换算。

**精度**控制显示方式。在“设置 → 精度”分别设置各单位的小刻度、主刻度、自动标注与 0–4 位小数，显示舍入不改变内部位置计算。

### 吸附与窗口布局

| 操作对象 | 可吸附目标 |
| --- | --- |
| 新建或移动参考线 | 定位点、屏幕边缘、窗口边缘、控件及可识别的图像边缘 |
| 连续测距节点 | 定位点、参考线和屏幕边缘 |
| 外部窗口 | 参考线和屏幕边缘，不直接吸附定位点 |

启用对应吸附选项后，按住吸附键（默认 `Left Ctrl`）操作。拖动外部窗口时会预览目标区域，松开鼠标完成吸附；默认调整位置和大小，也可改为仅调整位置。

参考线的像素边缘检测在后台执行，并过滤过期结果；吸附状态下松开吸附键，可立即恢复自由拖动。

### 显示、隐藏与清理

| 入口 | 作用范围与规则 |
| --- | --- |
| 单击角落按钮 | 只切换当前屏幕，按钮始终保留，方便再次显示 |
| 托盘显示/隐藏 | 统一切换所有屏幕；开启“托盘隐藏标尺时隐藏角落按钮”后，角落按钮也随托盘操作隐藏、恢复 |
| 角落右键菜单的清除操作 | 清除当前屏幕的对应内容 |
| 托盘菜单的清除操作 | 清除所有屏幕的对应内容 |

角落按钮的隐藏方式可选“全部隐藏”或“只隐藏标尺”：前者包括参考线、标点与测距线，后者保留这些内容。跟随托盘隐藏角落按钮默认关闭，只有开启托盘图标时才可启用。角落按钮相关选项集中在“设置 → 标尺”。

“全部清除”包含参考线、标点与测距线，定位点单独管理。**清除前确认默认关闭**；需要确认范围与数量时，在“设置 → 系统”开启。

## 默认按键

以下均指键盘左侧按键，可在“设置 → 按键”修改；开关与拖拽模式以当前设置为准。

| 操作 | 默认方式 |
| --- | --- |
| 移动参考线、标点 | `Left Shift` + 左键拖动 |
| 删除参考线、标点、整条测距结果 | `Left Shift` + 双击 |
| 吸附 | 操作期间按住 `Left Ctrl` |
| 启动测距 | 单独按住 `Left Alt` 500 毫秒 |
| 仅垂直 / 仅水平快捷测距 | 测距触发后按 `Left Shift` / `Left Ctrl` |
| 完成并闭合连续测距 | 双击终点或 `Enter` |
| 穿透标尺操作下方窗口 | 按住 `Left Ctrl` 操作标尺区域 |

设置、帮助等窗口打开时，桌面功能仍可使用。鼠标位于前台工具窗口内时不会启动测距，移到窗口外即可操作。

## 设置与数据保存

设置包含标尺、参考线、标点、测距、吸附、按键、定位点、物理校准、精度和系统页签。“应用”立即保存并生效，无需关闭窗口。标尺、参考线和测距透明度均可设为 `0%`。

| 数据 | 保存方式 |
| --- | --- |
| 设置、定位点、校准及精度 | `settings.json` |
| 参考线位置 | `guidelines.json`，默认开启位置保存 |
| 标点位置与图片 | `markers.json`、`marker-assets`，默认开启位置保存 |
| 连续测距结果 | 仅保留到本次运行结束 |

- **便携模式**：程序旁存在 `portable.txt`，配置保存在程序目录。发布脚本默认生成此文件。
- **普通模式**：程序旁没有 `portable.txt`，配置保存在 `%APPDATA%\ScreenRuler`。
- **升级**：先退出程序并备份配置目录，再更新程序文件；保留配置、图片及原有 `portable.txt` 状态。
- **切换保存模式**：退出程序后添加或删除 `portable.txt`，并按需手动迁移配置；切换模式不会自动搬移数据。

## 构建与验证

在 Windows 上准备支持 `net5.0-windows` 的 .NET SDK（项目当前使用 .NET 5 / WPF），下载源码后在仓库根目录执行：

```powershell
dotnet restore ScreenRuler.sln
dotnet build ScreenRuler.sln -c Release
dotnet test ScreenRuler.Tests/ScreenRuler.Tests.csproj -c Release
dotnet run --project ScreenRuler/ScreenRuler.csproj -c Release
```

桌面拖动、多屏、按键拦截和吸附效果还需按[手动验证清单](docs/MANUAL_VERIFICATION.md)检查。

使用现有脚本生成便携包内容：

```powershell
# 精简版，需要 .NET Desktop Runtime 5.0 x64
.\publish.ps1 -OutputDir .\publish\framework-dependent
```

脚本会先清空指定输出目录，应使用专用构建目录。打包、版本标签、Release 附件与发布操作见 [1.2.1 发布指南](docs/RELEASE_1.2.1.md)；可直接使用[版本说明](docs/RELEASE_NOTES_1.2.1.md)。
